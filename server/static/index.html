📚 Mathematical Formulations & Viva Reference Guide

1. Weighted Centroid (Spatial Baseline)

x = Σ(s_i * x_i) / Σ(s_i), y = Σ(s_i * y_i) / Σ(s_i)

Simple fast baseline. Biased toward the center of the polygon when noise is high, but provides robust initial guess.

2. Concentration-Based Trilateration

ln(s_i) = ln(A) - (n/2) * ln(d_i² + r_0²)

Solves non-linear least squares for (x, y, ln A). The unknown source strength A is estimated simultaneously without per-node calibration.

3. Machine Learning (Random Forest)

Feature Vector = [s_A/S_tot, s_B/S_tot, s_C/S_tot, ln(1 + S_tot)]

Scale-free normalized input features handle variable source release rates and overcome indoor wall reflection distortions.
